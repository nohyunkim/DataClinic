## 주요 기능

- CSV 업로드: 최대 5MB, UTF-8·BOM·CP949 지원
- 데이터 진단: 결측치, 중복 행, 자료형, 기초 통계 분석
- 데이터 정제: 결측 행 삭제, 평균·중앙값·최빈값 대체, 중복 제거
- 전후 비교: 정제 전후 품질 지표 및 데이터 변화 확인
- CSV 다운로드: 정제 결과를 CSV로 내보내기
- 정제 레시피: JSON 저장·불러오기 및 다른 데이터에 재적용

## 핵심 구현 및 개선

### 1. 원본 데이터 보호

원본과 작업 데이터를 분리하고, 정제 전 예상 영향을 확인한 후 사용자가 직접 적용하도록 구현했습니다.

### 2. 데이터 처리 성능 개선

정제 미리보기의 중복 진단 연산을 제거하여 약 5MB CSV 기준 처리 시간을 1,790.5ms → 985.5ms(약 45% 감소)로 개선했습니다. (Node.js 환경, 5회 측정 중앙값)

### 3. CSV 보안 및 예외 처리

CSV 수식 주입 위험을 완화하고, 정상 음수 데이터 보존과 인코딩·파일 구조 예외 처리를 위한 테스트를 추가했습니다.

### 4. 정제 레시피 재사용

정제 작업을 순서대로 기록하고 JSON으로 저장합니다. 불러오기 시 컬럼 호환성을 검증하며, 재실행 실패 시 부분 적용을 방지합니다.
