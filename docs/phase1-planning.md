# DataClinic — Phase 1. 서비스 기획

- 문서 상태: **확정**
- 결정일: 2026-11-22
- 범위: 서비스 목적, 초기 사용자, 차별화 전략, MVP 기능 범위
- 관련 단계: Phase 2 아키텍처 설계, Phase 3 UI/UX 설계

## 1. 프로젝트 개요

**DataClinic**은 사용자가 CSV 파일을 업로드하여 데이터의 품질을 진단하고, 문제의 위치와 의미를 확인한 뒤, 적절한 정제 방법을 직접 선택하고, 정제 전후 변화를 검증하여 CSV로 내려받는 웹앱이다.

핵심 사용자 흐름:

**CSV 업로드 → 데이터 품질 진단 → 문제 확인 → 정제 방법 선택 → 적용 전 영향 미리보기 → 사용자 승인·정제 적용 → 전후 비교 → CSV 다운로드**

서비스 목표는 기능을 많이 넣는 것이 아니라, 실제로 사용할 수 있는 완성도 높은 서비스를 개인 개발로 완성하고 무료 배포하는 것이다. 데이터 분석·전처리 역량뿐 아니라 사용자 중심 제품 기획, UI/UX, 구현, 테스트, 배포 과정도 포트폴리오에 남긴다.

## 2. 해결할 문제

CSV 데이터에는 빈 셀, 동일한 행의 중복, 특이하게 큰 숫자 등 분석에 영향을 주는 요소가 있을 수 있다. Excel이나 Pandas로 확인할 수 있지만, 분석 입문자는 다음 과정을 하나의 흐름으로 수행하기 어렵다.

1. **발견:** 어디에 어떤 데이터 문제가 있는지 찾는다.
2. **판단:** 해당 값이 실제 오류인지, 어떻게 처리할지 결정한다.
3. **검증:** 정제가 데이터 손실이나 통계 변화를 얼마나 만들었는지 확인한다.

예: 구매금액이 매우 큰 관측치는 이상치 **후보**일 뿐, 실제 정상 거래일 수 있다. 앱은 임의로 오류라고 단정하거나 자동 삭제하지 않는다.

## 3. 초기 타깃 사용자

**초기 타깃(확정): CSV 기반 데이터 분석 과제를 수행하는 입문자·취업 준비생**

- 현재 사용 도구: Excel, Colab, Pandas 등
- 주요 불편: 결측·중복 처리 코드를 작성하거나 결과를 해석하기 어려움
- DataClinic의 제공 가치: 코드 없이 문제를 확인하고, 정제 방법과 결과의 차이를 이해하도록 돕는 사용 경험
- 채택의 한계: 프로그래밍 자체를 학습하거나 복잡한 자동화를 수행해야 한다면 기존 도구가 더 적절할 수 있음

향후 확장 후보로는 간단한 CSV를 자주 점검하는 Excel 중심 실무자가 있다. 본 프로젝트가 모든 분석 도구를 대체하는 것을 목표로 하지는 않는다.

### 수요·사용성 검증 계획

- 분석 입문자 약 5명을 대상으로 정상·결측·중복 데이터가 섞인 예시 CSV로 사용성 테스트
- 앱 사용법을 미리 설명하지 않은 상태에서 업로드 → 문제 위치 파악 → 정제 → 전후 변화 설명까지 수행하도록 관찰
- 초기 목표(검증 전 제안치): 5명 중 4명 이상이 파일 업로드, 문제 위치 찾기, 전후 변화 설명을 각각 성공
- 위 숫자는 **목표**이지 이미 측정된 결과가 아님

## 4. 현실적인 차별화 전략

기존 도구에도 데이터 품질 진단·정제·변환 이력 기능이 존재한다. DataClinic은 기능의 독점성이나 기존 도구보다 우수한 성능을 주장하지 않는다.

| 비교 도구 | 기존 도구의 강점 | DataClinic의 집중 지점 |
| --- | --- | --- |
| OpenRefine | 강력한 정제·변환 작업 | 초보자가 문제와 정제 영향을 쉽게 해석하도록 안내 |
| Power Query | 폭넓은 데이터 변환과 단계 관리 | 설치·학습 부담을 줄인 단순 CSV 진단 흐름 |
| ydata-profiling | 자동 데이터 프로파일링 리포트 | 결과 확인에서 끝나지 않고 정제 선택·비교까지 연결 |

**핵심 차별화 문장:** 데이터 정제를 대신 결정하는 도구가 아니라, 사용자가 데이터 문제와 정제 결과를 이해하고 안전하게 개선하도록 돕는 도구.

## 5. MVP-1 — 첫 배포 범위

### 반드시 구현할 기능

1. **CSV 업로드**: 파일 선택, 드래그 앤 드롭, 샘플 CSV, 형식·크기 검증, 파싱 오류 안내, 미리보기
2. **구조 파악**: 행·컬럼 수, 컬럼명, 자료형 추론, 컬럼별 결측 개수·비율, 고유값 수, 숫자형 컬럼의 기본 통계
3. **핵심 품질 진단**: 빈 셀(결측치)과 완전 중복 행 탐지, 문제가 발생한 행·컬럼 위치 표시, 쉬운 설명
4. **기본 정제**: 결측 행 삭제, 숫자형 평균·중앙값 대체, 자료형에 맞는 최빈값 대체, 완전 중복 행 제거
5. **안전한 적용**: 원본 보존, 적용 전 변경 예상 결과 및 영향 미리보기, 사용자가 명시적으로 승인할 때만 작업 데이터 변경
6. **전후 비교**: 행 수·결측치·중복 수·기초 통계 변화 및 데이터 손실 비율
7. **결과 다운로드**: 정제된 CSV, Excel 한국어 표시를 위한 UTF-8 BOM 옵션, CSV Formula Injection 대응

### MVP-1 후반 또는 첫 배포 이후 재검토

- **IQR 기반 이상치 후보 진단**: 초기 핵심 완성에 방해되면 뒤로 미룸. 포함하더라도 후보 탐지만 하고 수정·삭제는 제공하지 않음
- **컬럼별 결측 비율 막대그래프**: 필요한 경우 후반 추가
- **숫자형 분포 히스토그램**: 첫 배포 이후로 미룰 수 있음
- 차트는 최대 2종으로 제한하고, 데이터 테이블과 진단 결과 이해를 우선함

### MVP-1의 명시적 제외

- 회원가입 및 로그인
- 데이터베이스 기반 사용자 파일 영구 저장
- 이상치 자동 삭제·변경
- 레시피 기록·재적용
- Excel 파일 직접 업로드, 고급 정제 규칙, PDF 보고서
- 필수 유료 API 및 외부 실시간 데이터 의존

## 6. MVP-2 — 정제 레시피

MVP-1 배포 후, 실제 정제 작업 순서의 기록, JSON 내보내기·가져오기, 대상 컬럼 및 자료형 호환성 검사, 같은 구조의 CSV에 재적용, 실패 원인 제시 및 결과 재현성 검증을 추가한다. **MVP-2는 MVP-1 배포를 지연시키지 않는다.**

## 7. 제품·안전 원칙

- 업로드 파일은 개인정보를 포함할 수 있으므로 불필요한 서버 전송을 피한다.
- 원본은 불변이며, 작업 데이터와 명확히 구분한다.
- 각 정제 방법의 의미, 적용 조건, 예상 데이터 손실을 설명한다.
- 자료형에 적합하지 않은 정제 방법은 비활성화한다.
- 결측 **셀 수**, 결측을 포함한 **행 수**, 중복 **행 수**를 혼동하지 않는다.
- 파일 오류, 빈 데이터, 전부 결측인 컬럼, 정제 후 행이 0개인 경우도 다룬다.
- 한국어 UI와 접근성, 데이터 탐색의 가독성을 우선한다.

## 8. 완료 기준 및 검증 항목

- 로그인 없이 CSV 업로드부터 진단·정제·비교·다운로드까지 완료 가능
- 검증용 샘플의 결측 및 중복 계산이 예상값과 일치
- 정제 결과가 예상값과 일치하고 원본이 변경되지 않음
- 한국어 CSV, 인코딩 오류, 비정상 파일, Excel 다운로드 호환성 검증
- 브라우저에서 실행할 수 있는 데이터 크기와 처리 성능을 실제 측정
- 첫 방문 사용자가 파일 업로드 방법과 다음 단계를 이해할 수 있음
